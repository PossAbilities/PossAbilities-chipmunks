# Security Policy

Cherwell Chipmunks handles personal and safeguarding-relevant data about
children (names, dates of birth, photos, medical information) and about the
PossAbilities staff who book them in. We take reports of security issues
seriously.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security report.

Instead, email **digital@possabilities.org.uk** with:

- A description of the issue and its potential impact
- Steps to reproduce it (if applicable)
- Any relevant logs, screenshots, or proof-of-concept

We'll acknowledge your report as soon as we can and keep you updated as it's
investigated and fixed. Please give us a reasonable amount of time to address
an issue before disclosing it publicly.

## Scope

This covers the Cherwell Chipmunks application itself (this repository) and
its production deployment at `chipmunks.possabilities.org.uk`. Please don't
run active exploits, load-test, or attempt to access real booking data
belonging to other families — report the issue and we'll verify it.

## Supported versions

Only the `main` branch / current production deployment is supported. There
are no maintained older versions.
